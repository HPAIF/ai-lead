# The lead's follow-ups

> Only the lead's own coordination follow-ups (members keep their own deadlines). Rows with status
> `open` and a due date within 30 days are shown by the session hook, so keep the format exactly:
> `| ID | YYYY-MM-DD | type | what | source | open/done/dropped |`. Use `—` when there is no date.
